## Question

With the MIN_HOST eligibility fix, does the launcher default (sparse on, below the threshold at 64k) run 64k as fast
as BONSAI_SPARSE=0?

## Why

P115: on the old build, FA_SPARSE set with no sparse op cost -20.6 % at 64k; P118 / the 4070 found the cause (no
prefetch below MIN_HOST). product-sparse has the fix. The 4070's step 2: "64k with the default MIN_HOST=32768 vs
BONSAI_SPARSE=0. Gate: within 2 %. This is the routing-fix check."

## Plan and gate

Script header: "Gate (declared here, before the run): default within 2 % of BONSAI_SPARSE=0 on mean decode at 64k in
both rounds; 0 sparse ops at 64k; 0 one-token; trace min free >= 60 MiB. (P115 on the old build: -20.6 %.)"

The 4070's default rule (#21, 02:19Z, before this run): "64k within ~5 % of BONSAI_SPARSE=0: sparse on by default on
8 GB at 262k; 64k worse than that: I wait for the 8-bit bounds."

## Method

Four servers alternated: off_r1 (22:40), def_r1 (22:45), off_r2 (22:54), def_r2 (22:59). quick_tps 64000 each (code,
prose, bash), a 10 s trace, launcher kv lines, sparse_mask line count.

## Deviations, incidents, void runs

- def_r1's prose item evaluated 64,005 tokens (a second full prefill, a prompt-cache miss), not 512. Decode of that
  item is not affected; prefill rates are.
- The two off arms differ by 5 % (36.2 vs 38.0) with lines 256 cells apart. Their loaded server sizes differ (7,463 vs
  7,523 MiB). P126 / P126b show the same pattern: see P126b.
- The run came after the power cut (events E32). The routing reading (0 sparse ops) does not depend on that.

## Verdict

FAIL as written; routing fix confirmed. Notebook: "routing fix confirmed (0 sparse ops at 64k); 64k -7.0 % from the
shorter line - gate FAIL (2 % / 5 %). Per the 4070's rule: wait for int8 bounds -> P127."

## Toolbox (for the next model)

- Method: check a fix by its own signal (0 sparse ops) and the speed gate separately; here the signal passed and the
  speed gate failed for another reason (the line).
- Pitfall: free VRAM at 64k overstates spare room for a table that fills with depth; trace the deepest point.
