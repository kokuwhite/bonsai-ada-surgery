## Question

Does q3_0 K/V cost any task quality on code with the 8 GB 262k launcher?

## Why

P108 (PPL) and P114 (copies, needles) showed no quality cost. A task score is the last gate before a default change
(P31 / P32 method for q4_0).

## Plan and gate

Notebook (P114 entry): "P117 (queue 69i, after P109b; gate in its header): HumanEval 164 medium, temp 0, 8 GB 262k
launcher, q3_0 (bin-q3kv). Pass: >= 157/164 (lowest q4_0 8 GB result, P31); report failures vs P87 (158/164)."

Script header: "Gate (declared here, before the run): q3_0 >= 157/164 (the lowest q4_0 8 GB result, P31) -> no
quality cost on code; report the failed task ids vs P87's 6 failures."

## Method

One server, then bench/humaneval_run.py --arm medium --temp 0 --max-tokens 20480 (same harness as P87), 164 tasks in
order.

## Results

- pass@1 97.56 % (160/164), 2,810.3 s.
- Failed: HumanEval/32 (AssertionError, 1,666 tokens), /39 (empty answer, 7,870 tokens, 145.1 s), /132
  (AssertionError, 20,686 tokens, 379.9 s), /145 (AssertionError, 1,710 tokens).

PASS. Notebook: "Reading: no loss on code (greedy flips), not a gain. Gate >= 157: PASS."
