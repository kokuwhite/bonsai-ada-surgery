## Question

Does the shipped bundle-20261011 (tier-graphs) run the P99 deep agent session to the end, and how do the per-turn
walls and decode speeds compare with P99 (bundle-20261010)?

## Why

Cary asked whether the 8 GB setup is usable at depth. P99 answered for bundle-20261010 (18/18 turns from 133k to
259.5k tokens). P119 repeats it on the shipped tier-graphs bundle, and P120 on sparse, so the three can be compared
turn by turn.

## Plan and gate

Notebook (P109b entry): "P119 / P120 (queue 69j / 69k, after P117; gates in their headers): the P99 deep agent session
(150k start, 25 turns x 2.5k) on bundle-20261011 (P119) and with sparse (...; P120). Answers Cary's 'usable at
depth?' with per-turn walls: P99 vs P119 vs P120."

Script header: "P119: P99 again on the shipped bundle-20261011 (patch 0053 tier-graphs), main launcher defaults, layer

one-token, server alive, trace min free >= 60 MiB, no bad_alloc / CUDA error. Report per-turn wall / tg vs P99
(bundle-20261010)."

## Method

(Planned.) One server; deep_soak.py --start-tokens 150000 --turns 25 --turn-tokens 2500; free VRAM every 10 s; after
the session: a health check and a count of "cache size limit", "bad alloc" and "CUDA error" lines in the server log.
