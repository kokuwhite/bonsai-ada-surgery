## Question

Does the deep agent session (150k start, 25 turns of ~2.5k tokens) run to the end with sparse host-tail reads on,
and are the per-turn walls lower and the decode speeds higher than P119 past ~100k of host tail?

## Why

P115 measured sparse 2.68x dense at 245k in single requests. A real session adds prompt-cache reuse, checkpoints and
growing depth. P99 / P119 / P120 give per-turn walls for the same session on three engines.

## Plan and gate

Script header (current version): "P120: P99 / P119 on product-sparse (bin-psparse8 = c8bbb1898 int8 bounds, P127;
launcher 8a47ffe; changed before the run) with the launcher-sparse defaults (sparse on, MIN_HOST 32768, page bounds
counted in the line, graphs on via 0053, packed mask on, lookup on). [Rewritten 2026-10-14 before it ran: it was
planned on bin-sparse7 with margin 475, f16 mask and graphs off.] Gate (declared here, before the run): all turns OK,
0 one-token, server alive, trace min free > 0, no errors. Report per-turn wall / tg vs P119 (expect lower walls and
higher tg past ~100k host tail)."
