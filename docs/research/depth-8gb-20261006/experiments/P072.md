## Deviations, incidents, void runs

- P72 (first run) failed. Receipts: "sha256sum: failed to set file descriptor text/binary mode: Bad file
  descriptor" and "tar: This does not look like a tar archive" (the tar in the task's PATH could not read the zip).
  `find` found no llama-server.exe, `dirname ""` gave ".", and the script copied the working folder (C:\bonsai\8gb)
  into bin-8gbfix (receipts/p72/files.txt lists DECISIONS.md, scripts, receipts ...). Every server then failed with
  "llama-server.exe missing". lookup_ab.py got "connection refused".
- False-pass risk: the P72 summary printed "0 one-token" for arms that never started. P72b's summary also greps
  "did not" so a dead arm shows.
- Fix: the zip was extracted by hand (sha256 aaf7637e...fe09, engine 142d5105d); P72b queued first. Later release
  checks (P79, P88) use Get-FileHash and Expand-Archive and stop on a missing exe.
