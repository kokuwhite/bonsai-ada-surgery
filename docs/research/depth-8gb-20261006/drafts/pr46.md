Patch 0046: `--checkpoint-every-nt N` (env `LLAMA_ARG_CHECKPOINT_EVERY_NT`, off by default). The 8 GB preset sets 8192 when the engine has the option.

## Problem

This hybrid model keeps context checkpoints (the recurrent state) only at user-message starts and just before the prompt end (`server-context.cpp`: mid-message checkpoints are skipped). Upstream removed its `--checkpoint-every-nb` (#20087) and has the same rule today. So a prompt that changes inside one long message is processed again from the start: an edited tool result, a file sent again, a benchmark that appends different tasks to one long message. On the RTX 2060 SUPER that is 272-294 s per request at 64k, and 760-866 s at 120k (P50).

## Change

In the prompt loop, a batch start that is at least N tokens past the last checkpoint also keeps its checkpoint (`server-context.cpp`, about 5 lines; option in `common/arg.cpp`, field in `common/common.h`). Restore is unchanged: the server already restores the nearest checkpoint at or before the divergence and processes the tail again.

Engine: fork branch `patch-0046-ckpt-every-nt` = `bonsai-q8-product` `142d5105d` + `5251968b0`.

## Receipt (RTX 2060 SUPER, `lookup_ab.py` at 64k, 11 requests on one server, drafting preset with lookup, shared pool off)

| | requests after the first (wall s) | text |
| --- | --- | --- |
| N = 0 (today) | 272-294 | reference |
| N = 8192 | 18-58 | 22 of 22 identical to N = 0 (control and tier-redirect-off arms) |

The log shows the deep restores: `restored context checkpoint (pos_min = 63492, pos_max = 63492, n_tokens = 63493, n_past = 63493, size = 167.944 MiB)`. MTP off, `GGML_GDN_STATE_GATHER=1` and tier redirect/prefetch off all gave correct text with it too. An earlier run of this patch (P59) gave wrong text; that run still had the shared CUDA pool on, the bug fixed in PR #10 / patch 0045.

Cost: each checkpoint holds the recurrent state, about 170 MiB of system RAM, at most 32 per slot (`--ctx-checkpoints`). A checkpoint copy is one device-to-host transfer per N tokens of prefill.

Receipts: `receipts/ckpt_every_nt_8gb.jsonl` (P71 arms + the N = 0 run).
